# Практическая работа №3: Программная сеть с маршрутизацией, шифрованием и беспроводным сегментом

## 📌  Описание проекта
Данный проект является развитием предыдущих практических работ. В отличие от первой работы (Клиент → Сервер) и второй (Клиенты → Один роутер), здесь реализована распределённая программная сеть из **нескольких маршрутизаторов**. 

Маршрутизаторы самостоятельно строят карту сети, находят кратчайший путь с помощью **алгоритма Дейкстры**, передают пакеты друг другу и поддерживают **шифрование данных** (XOR), чтобы промежуточные узлы не могли прочитать сообщение.
